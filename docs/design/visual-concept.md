# 당신의 여정 — 비주얼 컨셉: "종이 위의 판화"

> 따뜻한 종이 위에 먹색 잉크로 찍은 픽셀 판화.
> 조용한 오솔길을 걸으며 기록을 심고, 심은 것이 깨어나 꽃이 된다.

## 왜 이 방향인가

- Arden의 취향: 레트로 픽셀 아트. 레퍼런스는 흑백 Y2K 픽셀/디더링 보드 (스파클 ✦, 디더링 질감, 가는 선 픽셀).
- 타깃(중년 여성, 첫 사용자는 어머니)에게 픽셀 전면 테마는 리스크: 세대 노스탤지어 불일치("게임 같다"), 종이 일기장 메타포와 충돌, 장문 읽기 피로감.
- 해법: 레퍼런스의 "검은 종이에 흰 잉크"를 **"따뜻한 종이에 먹 잉크"로 반전**. 픽셀은 게임이 아니라 판화·인쇄물의 언어가 된다 — 어른스럽고, 유치하지 않다.
- 목업 3종(잉크 판화 / 파스텔 8비트 / 하이브리드) 비교 후 **잉크 판화 원안 채택** (2026-08-13). 파스텔을 포인트로 얹은 하이브리드는 판화의 힘이 빠져서 기각.

## 확정된 것

### 1. 픽셀이 사는 곳 (존 구분)
- **픽셀 O**: 홈 여정 경로(메인 무대), 타임캡슐 오브제와 봉인/개봉 연출, 빈 상태 일러스트, 소소한 장식.
- **픽셀 X**: 쓰기·읽기 화면(종이 질감 유지), 본문 타이포, 설정 등 기능 화면.
- 원칙: **읽고 쓰는 공간은 편안하게, 픽셀은 포인트마다 숨겨둔 보물처럼.**

### 2. 세계관: 기록을 심으며 걷는 오솔길
- 여정 경로 = 오솔길. 일기 하나 = 한 걸음. 마일스톤 = 길가에 핀 꽃.
- 타임캡슐 = 심은 씨앗. 봉인 = 심기, 대기 = 흙두둑/봉오리(내용 비노출 스펙이 "아직 땅속"이라는 세계관으로 자연스럽게 해석됨), 개봉 = 껍질이 깨지며 깨어나는 개화 (마법소녀적 "깨어남" 서사 + 발아 은유의 결합).
- 반짝임(✦)은 마법의 흔적 — 개봉 가능해진 캡슐 등 특별한 순간에만, 아껴 쓴다.

### 3. 색 전략
- 바탕: 따뜻한 종이 (#FFFDF7 계열, 기존 테마 토큰 paper 유지).
- 픽셀 일러스트: 먹색(ink #3A3A3A) 단색 + 알파 농담 + 디더링. 판화/점묘 질감.
- 유채색은 **살구·구릿빛(accent #C08A5D, #E9B48C 계열) 한 방울만** — 캡슐 봉오리, 반짝임, 꽃 중심 정도.
- 초기 아이디어였던 "밝고 산뜻한 파스텔 전면"은 접음 (하이브리드 목업 기각으로 확인).

### 4. 픽셀 스타일 규칙
- 입자: 가는 그레인 (목업 기준 홈 장면 ~100px 논리 해상도, 통통한 8비트 아님).
- 하드엣지 유지 (image-rendering: pixelated 상당), 안티앨리어싱 없는 순수 도트.
- 디더링(체커보드·점묘)으로 음영 표현. 그러데이션 금지.
- OS 창 프레임·터미널·글리치 등 테크 레트로 요소는 쓰지 않는다.

### 5. 타이포
- 본문·UI 텍스트: 가독성 폰트 (v1은 스펙대로 시스템 폰트, 본문 18+).
- 픽셀 폰트: 원칙적으로 금지. 쓴다면 로고/아주 짧은 장식 한두 곳 이하 (추후 결정).

## 미결 (컨셉 명확화 후 결정)

- [ ] **일기 배경색(속지) 팔레트** — 기존 4종(종이/살구/연둣빛/하늘빛)을 새 컨셉에 맞춰 재검토. 속지는 일러스트가 아니라 "종이 고르기"이므로 판화 컨셉과 별개 축이지만, 톤을 맞출지 논의 필요.
- [ ] 홈 외 화면(목록, 열람, 설정)에서 픽셀 장식의 허용 범위.
- [ ] 아이콘·내비게이션 등 UI 크롬을 픽셀로 할지, 일반 벡터로 할지.
- [ ] 반짝임/개화 모션 규칙 (정지 도트 vs 최소 애니메이션).
- [ ] 다크 모드 여부 (판화 반전 — 검은 종이에 흰 잉크 — 이 자연스럽긴 함).
- [ ] 실제 도트 에셋 제작 방법 (직접 제작 도구, 해상도 그리드, 에셋 파이프라인).
