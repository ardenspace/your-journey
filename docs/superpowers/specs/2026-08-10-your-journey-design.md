# 당신의 여정 (Your Journey) — 기획 스펙

- 날짜: 2026-08-10
- 상태: 승인 대기
- 작성 경위: Arden과의 브레인스토밍 대화로 도출. 예전 프로토타입(`space3-your-journey`)의 타임캡슐·꾸미기 기획을 계승.

## 한 줄 정의

단 한 사람을 위한 일기장. 치료처럼 보이지 않는 치유.

## 배경과 사용자

- 첫 사용자이자 기준 사용자: Arden의 어머니. 중년 여성. 네이버 블로그와 종이 수첩으로 이미 기록 습관이 있음.
- 자기 연민이 깊지만 병원·상담소는 "남한테 어떻게 말하냐"며 거부. 이 앱은 상담사가 아니라 다정한 일기장인 척하며, 스며들듯 과거를 꺼내게 만들어 회고와 케어를 전달한다.
- 기기: Android 폰 + Android 태블릿. 태블릿 레이아웃을 처음부터 고려한다.
- 확장: Play Store 정식 출시(사업자 계정)로 다른 중년 여성 사용자까지.

## 핵심 원칙 (모든 기능의 판단 기준)

1. **앱은 일기를 읽었다는 티를 내지 않는다.** 위로는 구조에서 오지, 반응에서 오지 않는다. 일기 내용을 분석·반영하는 기능은 만들지 않는다.
2. **통제권은 언제나 쓰는 사람에게.** 질문은 끌 수 있고, 봉인은 본인이 정하고, 강요되는 것은 없다.
3. **스며들듯 깊어진다.** 질문은 오늘의 가벼운 이야기에서 시작해 몇 달에 걸쳐 어린 시절, 젊은 날, 후회와 화해로 서서히 나아간다.

## MVP 기능

### 1. 일기 쓰기 (기본 흐름)

- 자유 쓰기가 기본. 제목 선택, 본문 필수.
- 종이 일기장 감성 꾸미기 계승: 속지 디자인(줄노트/모눈/무지), 글꼴, 글자 크기·색, 배경색. 마지막 사용 설정이 다음 일기의 기본값.

### 2. 오늘의 질문 (앱의 척추)

- 큐레이션 질문 뱅크: LLM 없이 사람이 직접 설계·소유하는 질문들. "엄마를 아는 사람이 설계한 질문 여정"이 차별점.
- 장(章) 단위 아크: 1장 가벼운 오늘 → 이후 장에서 어린 시절 → 젊은 날 → 후회와 화해 순으로 깊어지는 시퀀스.
- 하루 1개 제시. 답해도 되고, 무시하고 다른 이야기를 써도 되고, 설정에서 질문 모드 자체를 꺼도 된다.
- 질문 진행은 순서 기반(사용자별 진행 위치 저장). 일기 내용에 따라 분기하지 않는다(원칙 1).

### 3. 타임캡슐

- 일기를 봉인하면 지정한 개봉일(1달/3달/6달/1년/직접 입력)까지 본인도 열 수 없다.
- 개봉일에 푸시 알림과 함께 열린다. "말을 거는 것은 언제나 과거의 나 자신"이라는 케어 장치.

### 4. 여정 시각화

- 홈 화면에서 기록이 쌓일수록 길이 이어지는 시각 메타포. 수치·통계·잔소리 없이 말없는 격려만.

### 5. 오프라인 우선 + 동기화

- 로컬 DB에 먼저 저장(네트워크 무관, 즉시). 서버는 조용히 백업·동기화.
- 같은 계정이면 폰↔태블릿에서 이어서 쓸 수 있다.

## 기술 아키텍처

- **앱**: Expo (React Native), 새 프로젝트로 시작(프로토타입 코드는 참고만). Android 우선, 태블릿 반응형 레이아웃.
- **로컬 DB**: SQLite (expo-sqlite). 오프라인 우선의 원본 저장소.
- **서버**: AWS 서버리스 — Lambda(API) + API Gateway + DynamoDB + Cognito(인증) + S3(이미지). 항상 무료 티어 범위로 설계. 계정 생성 직후 billing alarm 설정 필수.
- **알림**: 타임캡슐 개봉일 로컬 알림(expo-notifications).
- **배포**: Google Play 정식 출시 (사업자등록 기반 조직 개발자 계정). iOS는 비용 문제로 보류.

## 하지 않는 것

- LLM 기반 답장·질문 생성: 만들지 않는다. 비용 문제가 아니라 원칙 1(읽었다는 티를 내지 않는다)과 충돌하기 때문.
- 가족 공유·연결: 만들지 않는다. 이 일기장은 온전히 쓰는 사람만의 공간이다.
- 일기 내용 분석(감정 분석, 키워드 추출 등): 만들지 않는다.

## 나중으로 미루는 것

- iOS 출시 (Apple 개발자 계정 비용 문제로 보류)

## 성공 기준

- 어머니가 누가 시키지 않아도 꾸준히 쓴다.
- 질문 아크를 따라 과거 이야기가 일기에 나타나기 시작한다.
- "앱이 나를 지켜본다"는 느낌을 단 한 번도 주지 않는다.
